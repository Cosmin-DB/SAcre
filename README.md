# SAcre

Repositorio del diseno electronico SAcre / SmartFeedbackDevice.

## Contenido

- Proyecto KiCad principal: `sacre.kicad_pro`
- Esquematico y PCB: `sacre.kicad_sch`, `sacre.kicad_pcb`
- Librerias locales de simbolos y footprints para los componentes usados
- Modelos 3D y datasheets de referencia incluidos en el proyecto

## Uso

Abrir `sacre.kicad_pro` con KiCad. Las tablas `fp-lib-table` y `sym-lib-table`
estan versionadas para conservar las rutas de librerias locales del proyecto.

## Notas de versionado

El `.gitignore` excluye backups, caches, bloqueos de KiCad, historiales locales,
netlists/exportaciones regenerables y archivos comprimidos de respaldo.
